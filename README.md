# 포가튼 사가 이식 참여 신청

포가튼 사가 이식 작업 저장소는 비공개라서 초대받은 사람만 볼 수 있습니다.
참여하고 싶으면 이 저장소에 신청 이슈를 남겨 주세요. 확인한 뒤 신청한 깃허브 계정으로 초대를 보냅니다.

## 신청 방법
1. 깃허브에 로그인합니다.
2. [참여 신청하기](../../issues/new?template=join.yml)를 누릅니다.
3. 양식을 채워 **Submit new issue**를 누릅니다.

신청한 계정 아이디는 이슈에 자동으로 남으니 따로 적지 않아도 됩니다.

## 초대를 받으면
- 깃허브에서 보낸 초대 메일의 링크를 누르거나, 알림(🔔)에서 초대를 수락합니다.
- 수락 후 저장소 README의 **브랜치 규칙**을 꼭 읽어 주세요.
  - `main` 브랜치에는 저장소 주인 외 커밋·푸시 금지
  - 작업은 `develop_<사용자id>`, 배포는 `release_<사용자id>` 브랜치에서
